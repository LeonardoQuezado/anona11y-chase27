Development log

Log

What Melodie can do today, how its analyzer changed, and what each version added.

Versionv0.9 · October 2026
Analyzerv2.9 · ATF 4.1.1, Lint UAST v2, static rules v3, pre-processor v2, light mode

Available

  • Analysis with several LLMs, each with its own key and model typed on the page
  • Correction with a local or online model of your choice, followed by re-analysis
  • CHASE 2027 battery: test grid, calibration screens, manual repair, batch correction and re-analysis, CSV export
  • Validity checks for every ATF result (first pass read, light mode)
  • Reports with JSON and HTML export
  • Interface in English, text contrast at WCAG AA

Still to do

  • Report the correction of new categories (headings, descriptions, focus) apart from the frozen prompt v5
  • Light × dark mode comparison (the prompt forbids themes, so dark mode would measure Melodie's injection)
  • Rules for the remaining blind spots: unannounced state, gestures invisible to TalkBack, redundant descriptions
  • Visual diff between original and corrected code
  • Screens from real open-source apps as input

Analyzer versions

Every report records the analyzer version that produced it (meta.analyzer). Results from different versions are not directly comparable.

VersionDateChange
v1Sep 2026Custom ST/TT/CT checks. Used for the WebMedia results; had false positives in ST and text-field labels.
v2Oct 26Google ATF 4.1.1 replaces the custom checks; Lint maps Kotlin named arguments; calibration screens.
v2.1Oct 26Static rule ComposeSmallTouchTarget (column TT_static): Compose enlarges small targets at runtime, so ATF measures 48 dp.
v2.2Oct 26The static scanner reads a positional contentDescription.
v2.3Oct 26ATF waits for the Compose accessibility tree before the first pass, scrolls in overlapping steps and skips clipped elements.
v2.4Oct 26ATF results are deduplicated by content position across scroll passes.
v2.5Oct 26ATF always returns per-pass diagnostics, so a result of 0 can be checked.
v2.6Oct 26Static rules for headings, vague descriptions, focus loss on toggle and disabled fields showing data.
v2.7Oct 27The pre-processor no longer breaks valid code.
v2.8Oct 27The phone is put in light mode before ATF and the mode is recorded.
v2.9Oct 28The scroll between ATF passes is measured on the same tree the checks run on.

v0.9 — Artifact preparation

Oct 28–29, 2026 · current

  • Analysis: LLMs are picked from a list; each opens fields for its API key and model.
  • Correction: choice of correction model (lab server, Ollama, OpenAI-compatible server or online API) with its key.
  • Interface, server messages and README translated to English.
  • Text contrast raised to WCAG AA (4.5:1) on every page.
  • CHASE 2027 page added to the top menu; Dashboard, Fix and Scan removed from it.
  • Home page reduced to its first section; creator page and theme music removed.
  • Documentation and this log rewritten.
  • Artifact anonymized for double-blind review.

v0.8 — CHASE 2027 battery

Oct 26–28, 2026

  • Test mode redesigned around the battery: each test traced from analysis to correction and re-analysis.
  • Analyzer v2 to v2.9 (see the table above) and three calibration screens with known expected results.
  • Validity of each ATF result: per-pass diagnostics, wake-up of the device, forced light mode.
  • Manual repair of build failures, same protocol as the pipeline's automatic retry (up to 2).
  • Battery grid: delete or redo one step of one test, batch correction and re-analysis.
  • CSV with repair outcome, per-category regressions, unique defects and decorative nulls.
  • Final battery results, study dossier and manual check sheet for the flagged headings.

v0.7 — Interactive home

Oct 25, 2026

  • Melodie on the home page follows the pointer, blinks and falls asleep when idle.
  • Bug Smash: a mini-game started from Melodie's star, with waves, a shop and upgrades.
  • Smaller type on the tool pages, respecting the browser's font size preference.

v0.6 — Refined interface

Oct 14, 2026

Oct 9, 2026
